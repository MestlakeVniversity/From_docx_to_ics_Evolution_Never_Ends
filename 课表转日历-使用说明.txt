课表转日历 — 使用说明
================================

第一步：从 i西湖 导出课表（得到 .docx）
----------------------------------------
1. 打开 i西湖：工作台 → 教务系统 → 我的课表。
2. 点「打印」→「导出」→「导出至一个 Word 文件」。
3. 把导出的 .docx 保存并传到电脑上（微信文件传输助手 / 网盘 / 数据线均可）。

推荐方式（最简单，任何电脑、任何系统都行）
----------------------------------------
1. 双击打开「课表转日历.html」（会用浏览器打开）。
2. 点「打开 .docx」选择刚从 i西湖 导出的课表 Word 文档。
3. 点「解析课表」，在表格里核对并直接修改。
4. 设置「第1周周一」日期：请按自己学校校历改成本学期开学第一周的周一。
5. 点「导出 .ics」，得到日历文件。

桌面程序方式（exe，Windows 10 / 11）
------------------------------------
1. 双击「课表转日历.exe」即可运行（系统自带运行环境，无需安装）。
2. 如果弹出「智能应用控制已阻止此应用」或蓝色警告，任选其一：
   方法一（推荐）：右键「KejianToIcs.cer」→ 安装证书 →
      选「本地计算机」→「将所有证书都放入下列存储」→ 浏览 →
      选「受信任的发布者」→ 完成（需要管理员权限）。再双击 exe。
   方法二：Windows 安全中心 → 应用和浏览器控制 → 智能应用控制 → 关闭。
      再双击 exe。
3. 使用流程与上面相同。

导入 Outlook（建议导入为独立日历）
----------------------------------
· 网页版：日历 → 添加日历 → 从文件上传。
   可先「添加日历 → 创建空白日历」命名，再上传 .ics 导入到该日历。
· 手机版：日历 → 设置(齿轮) → 添加日历 → 从文件上传，导入时选「新建日历」。
· 桌面版：文件 → 打开和导出 → 导入/导出 → 导入 iCalendar(.ics)，
   并选择「作为新日历导入」。

从 Canvas 导入作业（可选）
----------------------------------
1. 打开 i西湖：工作台 → Canvas 学习系统 → 日历 → 日历源(Calendar Feed)，
   复制 ICS 地址。
2. 在电脑浏览器打开该地址，会下载一个 .ics 文件。
3. 回到本工具点「导入 .ics（作业）」，选择刚下载的 .ics 文件。
4. 作业会按截止时间追加到表格，与课表一起导出。
   注意：请先设好「第1周周一」；早于该日期的作业会被跳过。

注意事项
--------------------------------
· 「第1周周一」一定要按自己学校的校历填写，否则首次上课日期会偏。
· 时区保持 Asia/Shanghai 即可，提前提醒默认课程开始前 20 分钟。
· 同一门课每周上多次、或分不同周次（如 8~13 周与 14~16 周），应各占一行。
