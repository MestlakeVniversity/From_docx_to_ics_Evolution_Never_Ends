课表转日历 · 使用教程

把教务系统导出的 Word 课表（.docx）转换成 Outlook 日历（.ics）。流程：导出课表(.docx) → 打开 → 解析 → 校对 → 设置 → 导出 .ics → 导入 Outlook。

0. 先从 i西湖 导出课表（得到 .docx）

打开 i西湖：工作台 → 教务系统 → 我的课表 → 打印 → 导出 → 导出至一个 Word 文件。

把导出的 .docx 保存并传到电脑上（微信文件传输助手 / 网盘 / 数据线均可）。

1. 打开课表

点击「打开 .docx」选择刚从 i西湖 导出的 Word 课表文件。

2. 解析课表

点击「解析课表」。程序会自动定位「星期一…星期日」各列，解析出课程名、星期、上下课时间、起止周次、上课地点、任课教师和教学班代码。

3. 校对与修改

在表格中逐行检查并直接修改；「添加行」「删除选中行」用于增删条目。同一门课每周上多次、或分不同周次，应各占一行；地点有多个教室时用「 / 」分隔。

4. 设置导出参数

「第1周周一」填学期第一周星期一的日期；「时区」默认 Asia/Shanghai (UTC+8)；「提前提醒」为课程开始前多少分钟提醒（0 不提醒）；「日历名」为导入 Outlook 后的日历名称。

5. 导出 .ics

点击「导出 .ics」即可下载日历文件，可直接导入 Outlook。

6. 导入 Outlook（建议导入为独立日历）

网页版：日历 → 添加日历 → 从文件上传。想要独立日历，可先「添加日历 → 创建空白日历」命名，再上传 .ics 并选择导入到该新建日历。

手机版：日历 → 左上角头像/菜单 → 设置(齿轮) → 添加日历 → 从文件上传，导入时选择「新建日历」。

桌面版：文件 → 打开和导出 → 导入/导出 → 导入 iCalendar (.ics) 文件，并选择「作为新日历导入」。

7. 从 Canvas 导入作业（可选）

打开 i西湖：工作台 → Canvas 学习系统 → 日历 → 日历源(Calendar Feed) → 复制 ICS 地址。

在电脑浏览器打开该地址会下载一个 .ics 文件；回到本工具点「导入 .ics（作业）」，选择该文件即可。

作业会按截止时间追加到表格里，和课表一起导出成同一个日历。注意：请先设好「第1周周一」，早于该日期的作业会被跳过；导入后请核对截止时间。

常见问题

· 解析结果不对或漏课程？

个别课表排版特殊，直接在表格中修改相应行即可，无需重新解析。

· 某门课一周上两次或分周次？

拆成两行分别填写，程序会生成独立的周重复事件。

· 导入后时间错乱？

确认「时区」选了 Asia/Shanghai，且「第1周周一」日期正确。

· 如何删除已导入的旧日历？

网页版：左侧“我的日历”中悬停该日历 → 「⋯」→ 移除；若并入了默认日历，则逐条删除旧事件。手机版：日历 → 菜单 → 点日历旁 ⓘ → 删除日历。桌面版：右键该日历 → 删除。
